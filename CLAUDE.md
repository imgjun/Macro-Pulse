# Macro-Pulse - Claude Code Context

## What this project does

Daily market report bot. Fetches market data, grabs 5 images from the
`@yakjangsu` Telegram channel using Telethon MTProto, and sends a formatted
summary to Telegram.

Two modes, auto-detected by UTC hour or forced via `--market`:

- **KR mode**: Mon-Fri 17:00 KST (08:00 UTC)
- **US mode**: Tue-Sat 06:30 KST (21:30 UTC)

## Execution environment

**Runs on GitHub Actions.** This repository owns its schedule through
`.github/workflows/daily_report.yml`.

Production scheduler:

- `00 08 * * 1-5` for KR mode
- `30 21 * * 1-5` for US mode
- `workflow_dispatch` remains available for manual runs

The schedule source of truth is:

- `config/report_formats.json`
- `src/macro_pulse/workflows/schedule_sync.py`

Do not treat GCP cron as the runtime owner for this repository.

## Environment variables

All 5 must be present in GitHub repository secrets for scheduled runs. For local
development, they can also be stored in a local `.env`.

| Variable | Purpose |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Bot API token. Rotated on 2026-04-30. |
| `TELEGRAM_CHAT_ID` | Telegram user or channel ID for delivery. |
| `TELEGRAM_API_ID` | Telethon MTProto credential from my.telegram.org. |
| `TELEGRAM_API_HASH` | Telethon MTProto credential from my.telegram.org. |
| `TELEGRAM_SESSION_STRING` | Telethon StringSession generated by `uv run python scripts/generate_session.py`. |

## Key source files

| File | Purpose |
|---|---|
| `src/macro_pulse/app/cli.py` | Entry point. `resolve_mode()` auto-detects KR/US by UTC hour. |
| `src/macro_pulse/data/providers/telegram_channel.py` | Telethon fetcher for the latest `@yakjangsu` image batch. |
| `src/macro_pulse/reporting/screenshots.py` | Screenshot handlers. `yakjangsu` handler calls the Telethon fetcher. |
| `config/report_formats.json` | Per-mode config and workflow schedule source. |
| `src/macro_pulse/workflows/schedule_sync.py` | Syncs the generated workflow schedule block from config. |
| `scripts/generate_session.py` | One-time Telethon StringSession generator. |
| `.github/workflows/daily_report.yml` | Scheduled production runtime for KR/US reports plus `workflow_dispatch`. |

## How yakjangsu image selection works

Telethon reads recent messages from `@yakjangsu`, groups them by posting time
into 5-minute windows (`BATCH_WINDOW_SECONDS = 300`), picks the most recent
batch, and returns up to 5 images in chronological order.

## Common operations

**Check latest GitHub Actions run:**

- Open the repository Actions tab and inspect `Daily Macro Pulse Report`

**Manual local test run (dry run):**

```bash
uv run python src/main.py --market US --dry-run
```

**Regenerate Telethon session:**

```bash
uv run python scripts/generate_session.py
```

Then update `TELEGRAM_SESSION_STRING` in local `.env` and GitHub repository
secrets.
