# Macro-Pulse Claude Code Context

## Project summary

Daily market report bot.
- Collects macro/market data
- Builds HTML and Telegram summaries
- Uses Selenium for KR heatmaps
- Uses Telethon to fetch the latest full image batch from `@yakjangsu` for US mode

## Current verified state

- `US` screenshot target is `yakjangsu`
- `yakjangsu` fetch uses a **user** Telethon session, not a bot session
- Latest batch selection is based on `BATCH_WINDOW_SECONDS = 300`
- Default behavior is to download the **full latest batch**
- `MAX_POST_AGE_HOURS = 24`
- `capture_screenshots()` is async-aware
- `src/main.py` runs through `asyncio.run(...)`
- GitHub Actions has been cleaned up to **CI only**
- Do **not** assume GitHub Pages, GitHub report workflows, or GCP crontab are active
- Last verified GCP state: no active Macro-Pulse crontab entries
- Preferred validation environment right now: local Windows / WSL

## Required environment variables

### Telegram send
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

### Telegram read (MTProto)
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_SESSION_STRING`

`TELEGRAM_SESSION_STRING` must be a Telethon StringSession generated by:

```bash
uv run python scripts/generate_session.py
```
